Domain Name System (DNS) Revision Guide

1. Why do we need DNS?

Humans find it easy to remember text-based domain names (like www.wwt.org.uk), whereas network routers and computers require numerical IP addresses (like 172.67.182.44) to route data packets across the internet.

2. Hierarchical & Distributed Database

No single server holds every website on Earth. DNS is split across tiered servers worldwide: Local Cache → ISP Recursive Resolver → Root Servers (.) → Top-Level Domain Servers (.uk, .com) → Authoritative Name Servers.

3. Caching & Time to Live (TTL)

Once an IP address is resolved, both the ISP resolver and your local browser cache it for a set TTL period. Subsequent visits result in a Cache Hit, reducing internet traffic and loading webpages significantly faster. Skipping the cache can overload and take down an authoritative server under a query flood (SERVFAIL).
